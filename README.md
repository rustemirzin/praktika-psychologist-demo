# Практика

Демонстрационное рабочее место психолога: журнал клиентов, индивидуальные консультации, групповые встречи, календарь, опросники с расчётом результатов и справки.

Все клиентские данные вымышлены. Изменения хранятся только в localStorage браузера посетителя. Это открытая демка без регистрации; не вводите реальные пациентские данные.

Каталог содержит 33 инструмента: GAD-7, PHQ-9, полный IPIP-NEO-120 и 30 коротких шкал единой модели IPIP. Это не 33 независимые клинические методики. Русские формулировки — демонстрационный перевод без заявленной валидации. Результаты не устанавливают диагноз. Клинические скринеры доступны с 18 лет; большинство коротких IPIP-шкал — с 14 лет, без подростковых норм.

Источники: [IPIP-NEO-120](https://ipip.ori.org/30FacetNEO-PI-RItems.htm), [разрешение IPIP](https://ipip.ori.org/newPermission.htm), [руководство PHQ/GAD](https://www.phqscreeners.com/images/sites/g/files/g10016261/f/201412/instructions.pdf). Материалы IPIP и PHQ/GAD допускают воспроизведение и перевод; пояснения в демке не представлены как клиническое заключение.

Сайт без сборки. Для локального запуска: `python3 -m http.server 4328`, затем http://localhost:4328.
